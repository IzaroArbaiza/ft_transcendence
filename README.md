# 🏓 ft_transcendence

## 🧩 Overview

**ft_transcendence** is the final project of the 42 curriculum and consists of developing a complete **full-stack web application**.

The project combines frontend development, backend services, databases, authentication systems, real-time communication, and deployment concepts into a single application.

Our implementation recreates an online multiplayer **Pong platform**, allowing users to play matches, manage profiles, interact with other players, and track game statistics.

## 🎮 Gameplay

Players can challenge each other to Pong matches directly through the platform.

### Match Rules

- Two players compete in real time.
- Each player controls a paddle.
- The objective is to prevent the ball from passing your side.
- Points are awarded when the opponent misses the ball.
- The first player reaching the configured score wins the match.

### Controls

| Key | Action |
|------|--------|
| `W / ⬆️` | Move paddle up |
| `S / ⬇️` | Move paddle down |

## 🌍 Platform Workflow

1. Create an account or log in.

4. Start or join a Pong match.
5. Play in real time against other users.
6. Review match history and statistics.
7. Continue climbing the leaderboard.
